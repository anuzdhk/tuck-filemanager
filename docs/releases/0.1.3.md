## Tuck 0.1.3

<img src="https://raw.githubusercontent.com/anuzdhk/kivo-filemanager/v0.1.3/docs/screenshots/readme/main-light.png" alt="Tuck 0.1.3" width="860">

### New

- **Column view** (Ctrl+4, or the fourth view button): macOS-style columns. It starts as one column; each folder you open slides in a new column on the right, a file shows a preview at the end, and Back closes the rightmost column first. Left/Right move between columns.
- **AMOLED Black theme**: pure black window, sidebar and header, made for OLED screens.
- **Search field in the header**: "Search files… Ctrl+F" sits beside the path, and folds into the search button when a long path needs the room.
- **Separate partitions in the sidebar**: a separate /home or a second disk mounted from /etc/fstab now shows under Drives, with how full it is. Disks that aren't mounted show as "Not mounted".

<img src="https://raw.githubusercontent.com/anuzdhk/kivo-filemanager/v0.1.3/docs/screenshots/readme/columns.png" alt="Column view in the AMOLED Black theme" width="860">

### Improved

- **Sidebar redesign**: Favourites, Bookmarks, Drives, Network and Tags sections that fold (and stay folded), with the Places | Folders switch moved to the bottom bar beside Preferences and Cleaner.
- **Top bar**: the path now sits on the left, right after Back, Forward and Up.
- **Views remember you**: the view and sort order you last chose become the default for folders you haven't set yourself, so Column view stays on as you go deeper and after a restart.
- **Calmer selection**: tinted backgrounds with a thin border instead of bright accent fills.
- **Motion**: quick ease-out fades and slides when you switch views, open folders, and hover or select items. All of it turns off with Preferences › Reduce Motion, or when your desktop asks apps to reduce motion.

<img src="https://raw.githubusercontent.com/anuzdhk/kivo-filemanager/v0.1.3/docs/screenshots/readme/sidebar.png" alt="The redesigned sidebar" width="860">

### Fixed

- **Rating a file** in the Information panel no longer clears the selection and jumps the panel back to the folder.
- **AppImage updates** now replace the installed AppImage instead of adding a second copy, and clean up copies an earlier update left behind (with their menu entries). Restart Tuck from the Updates page when it's done.

### Install or update

```bash
curl -fsSL https://raw.githubusercontent.com/anuzdhk/kivo-filemanager/feat/strata/get.sh | sh
```

Already have Tuck? Open **Preferences › Updates › Check Now**. Packages below: `.deb` (Debian 13+, Ubuntu 25.04+), `.rpm` (Fedora 41+, openSUSE Tumbleweed), Arch, and an AppImage for everything else. Every file is listed in `SHA256SUMS`.

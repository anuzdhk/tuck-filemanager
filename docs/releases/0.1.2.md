## Tuck 0.1.2

<img src="https://raw.githubusercontent.com/anuzdhk/kivo-filemanager/v0.1.2/docs/screenshots/readme/main-light.png" alt="Tuck 0.1.2" width="860">

### New

- **Cleaner**: free up space by clearing caches that are safe to delete: file previews, browser caches, graphics shader and font caches, and pip / npm / Yarn / Go downloads. Other apps' caches and the Trash are listed but never ticked for you, a browser's cache is skipped while it's open, and your own files are never touched. Open it from the ✨ button at the bottom of the sidebar.
- **Drive usage in the sidebar**: Computer and every mounted drive show how full they are, with free space at a glance.
- **Preferences › Storage**: a card for each drive with used, free and total space, file system and mount point, plus Open and Eject.
- **Resizable sidebar**: drag its edge; double-click to reset. Tuck remembers the width.
- **Sidebar bottom bar**: Preferences and Cleaner, where the storage box used to be.

<img src="https://raw.githubusercontent.com/anuzdhk/kivo-filemanager/v0.1.2/docs/screenshots/readme/cleaner.png" alt="The Cleaner" width="860">

### Improved

- **Preferences › Appearance** starts with Readability, then keeps Theme, Accent Colour and Icons together.
- **Bookmarks** no longer repeat folders that are already under Places (GNOME adds Documents, Music, Pictures, Videos and Downloads to the shared bookmarks file).

### Fixed

- **Quick Look**'s top bar now uses the theme's colour instead of showing the desktop through it.

<img src="https://raw.githubusercontent.com/anuzdhk/kivo-filemanager/v0.1.2/docs/screenshots/readme/quick-look.png" alt="Quick Look" width="640">

### Install or update

```bash
curl -fsSL https://raw.githubusercontent.com/anuzdhk/kivo-filemanager/feat/strata/get.sh | sh
```

Already have Tuck? Open **Preferences › Updates › Check Now**. Packages below: `.deb` (Debian 13+, Ubuntu 25.04+), `.rpm` (Fedora 41+, openSUSE Tumbleweed), Arch, and an AppImage for everything else. Every file is listed in `SHA256SUMS`.
